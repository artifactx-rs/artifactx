# ArtifactX console

The `arx serve` web console, rendered from A2UI v1.0 messages by
`@a2ui/react`. The generated bundle is embedded into the `arx` binary with
`include_dir`; `crates/arx/ui/dist/` is checked in for `cargo install`.

## Build

```bash
npm ci --prefix crates/arx/ui
npm run build --prefix crates/arx/ui
cargo build -p artifactx
```

The `crates/arx/ui/dist/` bundle is checked in so `crates.io` users can
`cargo install artifactx` without Node; CI rebuilds it before Cargo and the
release workflow rebuilds it before packaging. `cargo build` fails with an
instruction if `crates/arx/ui/dist/index.html` is absent.

## Develop

```bash
npm run dev --prefix crates/arx/ui
```

Vite serves the app at `/ui/`; start `arx serve` separately and proxy the API if
needed. The production build uses `base: "/ui/"`, matching the embedded route.

## Catalog

`src/catalog.tsx` builds a custom React catalog from the A2UI v1.0 Basic
Catalog schemas. Text, Row, Column, Card, List, and Button are React primitives
styled with shadcn-style CSS tokens; components without an override use the
Basic Catalog implementation.

## Scope

The first slice is read-only: overview metrics, package search, and publish
activity. A2UI messages are generated by the Rust console module, not by a
language model. See `docs/adr/0032-a2ui-console.md`.
